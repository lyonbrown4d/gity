# Shared Frontend and Backend Localization

`crates/gity-i18n/locales` is the shared source of Chinese and English copy. Both the Rust Web app and server depend on this crate; `rust-i18n` embeds the assets at build time, so the browser does not need to download language packs at runtime.

Each asset maintains both `en`、`zh`。Existing English UI phrases remain the keys for compatibility. Register new messages in the shared directory; do not maintain the same copy separately in the server and Web app.

```rust
let message = gity_i18n::translate(
    "Type {path} to confirm deletion.",
    "zh-CN",
    &[("path", "team/project")],
);
```

Parameters use the library’s named-placeholder handling, while the application interface retains `{path}` template compatibility. Tests check for duplicate keys, completeness in both languages, matching placeholders, interpolation, and isolation between concurrent request languages.

## Web

The language choice is saved in browser preferences. Each JSON or upload request reads the preference again and sends `Accept-Language`; users do not need to sign in again after switching languages.

## Server

The server selects `zh` or `en` according to the quality weights and order in `Accept-Language`. Chinese regional tags such as `zh-CN` and `zh-TW` normalize to `zh`; unsupported languages fall back to English.

The request language is stored in Tokio task-local context; do not call global `set_locale`. Error responses are translated from the shared directory and include `Content-Language` and `Vary: Accept-Language`.

Status codes, machine-readable fields, and business identifiers do not vary by language. Known fixed error messages are translated; unknown dynamic content remains unchanged. A 500 response returns only a generic message; investigate the internal error in server logs.

## Update Language Packs

1. Add both `en` and `zh`, and avoid including business identifiers or secret values.
2. Keep each handwritten asset file at or below 300 lines and split files by function.
3. When adding a file, update the test manifest in `src/assets.rs` as well.
4. Run `cargo test -p gity-i18n -p gity-core` and the server request-language regression tests.
5. Check Chinese line wrapping on narrow screens and in buttons and tables.
